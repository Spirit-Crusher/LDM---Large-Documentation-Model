# LDM - Large Documentation Model

Local LLM-based documentation generator.

## Objective

Develop a lightweight, private, locally hosted AI application that generates structured technical documentation and operating procedures from heterogeneous source information.



## Inputs

- Commented source code and docstrings.

- JSON and YAML configuration/document definitions.

- PDF documents.

- CSV and Excel spreadsheets.

- Diagrams, flowcharts and images.

- Manual user instructions.



## Outputs

- Editable Markdown.

- Editable LaTeX.

- PDF conversion capability.

- HTML wiki interface planned for a future release.

 

## Quality requirements

- Source traceability.

- No unsupported factual claims.

- Explicit identification of missing information.

- Conflict detection.

- Technical validation.

- Human review and approval.

- Automated regression testing.
  
  

## Operating requirements

- CPU-only inference.

- Local processing.

- Offline operation after installation.

- On-demand generation.

- Modular and extensible architecture.

- Docker compatibility
